Merge Conflict Avoidance Plan

Goal
- Keep future PRs small and conflict-safe so they can merge cleanly in GitHub UI.

Plan
1) Revert-first baseline
   - Start from the current stable baseline (after reverting the large mixed commit).
   - Do not combine generated-file policy changes, packaging changes, docs scaffolding, and core math refactors in one PR.

2) Split into independent PRs (in this order)
   A. PR-1: syntax/exports only
      - Files: src/nas/bayesian.py, src/nas/__init__.py, src/benchmark/__init__.py, src/hardware/__init__.py
      - No packaging, no docs, no generated-table movement.

   B. PR-2: Conv2D backward + tests only
      - Files: src/layers/conv.py, tests/test_layers.py
      - Include finite-difference validation in same PR.

   C. PR-3: profiler + experiment metric wiring only
      - Files: src/hardware/profiler.py, neurospec/experiments.py, src/benchmark/research_suite.py, scripts/run_research_suite.py
      - No table deletions in this PR.

   D. PR-4: generated-table strategy only
      - Files: src/hardware/design_space.py, src/hardware/research_tables.py, .gitignore, scripts/generate_tables.py
      - If repository policy requires tracked generated files, keep them tracked and add header comments only.
      - If policy allows untracked generation, delete in this PR only and add generator + CI check.

   E. PR-5: docs/packaging only
      - Files: pyproject.toml, docs/source/*, README.md
      - Avoid touching runtime modules here.

3) Rebase discipline
   - Before each PR: rebase onto latest main.
   - Resolve conflicts locally, rerun tests, then push.

4) Conflict guardrails
   - One concern per PR, max ~5 files changed where possible.
   - Avoid editing the same high-churn files across multiple open PRs.
   - Keep generated artifacts and their generator changes in one dedicated PR.

5) Validation checklist per PR
   - Run: pytest -q
   - If hardware/profiler touched: python scripts/run_research_suite.py --use-cycle-model
   - If generators touched: run generator and verify deterministic output.

Outcome
- This sequencing minimizes overlap and should eliminate the complex multi-file merge conflicts seen in the prior combined PR.
