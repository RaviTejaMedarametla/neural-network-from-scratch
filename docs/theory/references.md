# References

This project draws inspiration from classic and modern ML systems literature:

1. LeCun et al., Gradient-Based Learning Applied to Document Recognition (1998).
2. Vaswani et al., Attention Is All You Need (2017).
3. Han et al., Learning both Weights and Connections for Efficient Neural Networks (2015).
4. Hinton et al., Distilling the Knowledge in a Neural Network (2015).
5. Jouppi et al., In-Datacenter Performance Analysis of a TPU (2017).

Hardware models in this repo are simplified estimators intended for comparative research prototypes.
